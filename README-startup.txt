開機自動啟動 —— 怎麼設定
==========================

1. 按 Win+R，輸入   shell:startup   按 Enter
   （會開啟「啟動」資料夾）

2. 把下面其中一個檔案的「捷徑」放進去：

   start-hidden.vbs        只有這台電腦連得到
   start-lan-hidden.vbs    手機、平板也連得到（同一個區網）

   放捷徑不要放原檔 —— 原檔要留在專案資料夾裡才找得到其他檔案。
   （在檔案上按右鍵 → 複製 → 到「啟動」資料夾按右鍵 → 貼上捷徑）

3. 下次登入 Windows 時就會自動啟動，而且看不到任何視窗。

   直接點 .vbs 也一樣「沒有反應」—— 那就是成功的樣子。
   要確認，執行 status.bat。


要選哪一個？
------------
如果你平常是點 start-lan.bat，那就選 start-lan-hidden.vbs。

但先想一下：手動點的時候，「開放給區網」是你每次自己決定的；
放進啟動之後它就變成一直開著。這個服務是純 HTTP，同一個網路上
的人都讀得到流量。家裡沒問題，不是你自己的網路就不要這樣做。


怎麼確認它有在跑？
------------------
執行 status.bat。它會告訴你：

   * 有沒有在跑、監聽哪個位址
   * 手機可以用的網址（LAN 模式時）
   * 最新那份記錄檔的最後幾行

或者直接用瀏覽器打開   http://localhost:8301/

記錄檔在 data\logs\，每啟動一次兩個檔，只保留最近 15 次：

   <日期時間>_LOG.txt       程式自己記的（掃描、登入、慢的請求…）
   <日期時間>_CONSOLE.txt   伺服器本身印出來的

啟動失敗要看 _CONSOLE.txt。像「位址已被使用」這種錯誤發生在記錄
機制啟動之前，只會出現在那個檔裡。

重複點兩次啟動器不會壞事 —— 第二次會看到
「already running on port 8301 - nothing to do」然後結束。


怎麼停掉？
----------
執行 stop.bat。

要取消開機啟動，把「啟動」資料夾裡的捷徑刪掉就好。


其他檔案是做什麼的
------------------
status.bat           它到底有沒有在跑？（先看這個）
start.bat            平常手動啟動：開最小化的視窗，並打開瀏覽器
start-lan.bat        同上，但開放給區網
run-server.bat       伺服器本身（會先檢查前端要不要重建）
build.bat            只重建前端，不啟動
start-dev.bat        開發用：Vite 熱重載在 5173（只有改程式時才需要）
stop.bat             停掉服務


網址變了
--------
以前是 :5173（Vite 開發伺服器），現在是 :8301。
前端已經編譯進後端，所以只剩一個服務、一個埠、一個行程，
執行時完全不需要 Node。手機上的書籤要改一次。
